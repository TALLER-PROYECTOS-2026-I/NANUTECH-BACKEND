HIGH CKV_AWS_76 Ensure API Gateway has Access Logging enabled — template.yaml
L93–105		 La API Gateway no tiene Access Logging habilitado. Sin logging es imposible auditar quién accedió y cuándo. Agregar AccessLogSetting con DestinationArn apuntando a un Log Group de CloudWatch en el recurso AWS::Serverless::Api.

HIGH CKV_AWS_120 Ensure API Gateway caching is enabled — template.yaml
L93–105		 API Gateway no tiene caching habilitado. El caching reduce latencia y protege backends de sobrecarga. Agregar MethodSettings con CachingEnabled: true y CacheDataEncrypted: true en la definición del stage.
Ver documentación →
